# Руководство по внесению вклада (Contributing Guidelines)

Мы приветствуем любые улучшения проекта, оптимизацию алгоритмов удержания трассы и доработку механической конструкции!

## Как внести свой вклад:

1. **Форкните репозиторий** и создайте отдельную ветку для вашей задачи:
   ```bash
   git checkout -b feature/optimization-pid
   ```
2. **Внесите изменения**:
   - Старайтесь сохранять стиль кода Arduino / C++ и комментировать нетривиальные формулы.
   - Если модифицируются 3D-модели, убедитесь, что они корректно открываются в стандартных слайсерах (Bambu Studio, Cura, PrusaSlicer).
3. **Проверьте работоспособность**:
   - Убедитесь, что прошивка компилируется без предупреждений с ядром ESP32 версии 3.x.
4. **Создайте Pull Request** с описанием изменений и прикрепленным шаблоном.

Спасибо за развитие проекта! 🚀
